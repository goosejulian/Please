# Stick Road Game

A black-and-white stick figure walks down a road and occasionally stops to say random text events.

## Fastest way to run (no local server)

From this folder, run:

```bash
./play.sh
```

That opens `index.html` directly via `file://...` in your default browser.

## Manual fallback (still no server)

Open this exact path in your browser:

```text
file:///workspace/Please/index.html
```

## Controls

- No controls required (auto-play)
- `Space` = pause/resume
